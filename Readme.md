# 📊 ONS Algeria Inflation Analysis

Comprehensive analysis of inflation trends in Algeria based on official 
data from the Office National des Statistiques (ONS).

## Overview
This repository contains detailed inflation data and analysis for Algeria 
covering the period **2015-2024**, extracted from the ONS Annual Consumer 
Price Index Report (Collections Statistiques N° 247/2025).

## Contents
- **Complete inflation dataset** (JSON format) with annual rates and CPI indices
- **Synthesis report** (French) with detailed analysis and visualizations
- **Statistical analysis** covering inflation trends and variations

## Key Data
- **Time Period:** 2015-2024 (10 years)
- **Base Index:** 2001 = 100
- **Source:** Office National des Statistiques - Algérie
- **Official Document:** Note annuelle IPC2024

## Highlights
- Inflation evolution from 4.8% (2015) through 9.3% peak (2022-2023) 
  to 4.5% (2024)
- Detailed year-by-year breakdowns and trend analysis
- Structured data for further analysis and visualization

## Language
- French documentation
- JSON data format for programmatic access
